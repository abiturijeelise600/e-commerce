# Climate Forward

A standalone React + Vite climate-awareness project. It includes an educational overview, a small illustrative travel/meal estimator, and action selections saved locally in the current browser.

## Run it

From this directory:

```bash
npm install
npm run dev
```

Build for production with `npm run build`.

## Notes

- No database or backend is used. Action selections remain in local browser storage.
- The emissions estimator is deliberately a rough educational illustration, not a complete footprint calculation or official measurement.
- External climate learning links point to the IPCC and United Nations.
